# 授業ノート

高校保健体育の教材を準備する静的Webアプリ。GitHub Pagesで公開。OCRは端末のブラウザ内で動き、写真・OCR本文をサーバーや有料APIへ送信しません。追加API料金はありません。

## OCR改善版 v5

- Tesseract.js/Core 7.0.0、jpn専用。英語モデルへのフォールバックなし。
- WorkerとLSTM/WASMを同梱。日本語学習データは初回にTesseract.jsの日本語データ配信元から取得し、可能なら端末にキャッシュ。
- データの取得・形式・Worker内の展開・日本語初期化を診断。生成した日本語テスト文字も認識して確認。
- 明るさ・コントラスト、小さな傾き、90度回転、元画像からの範囲切り出し。薄い文字には補正なしで再試行可能。
- 指で範囲を囲むか、スライダーで調整。段落・図表・注釈を個別に読み取って種類を指定。
- 低信頼度、日本語の割合が低い結果、文字数不足に警告。空欄は失敗。信頼度は正答率ではありません。
- 原画像と見比べてアプリ内で編集。各ページの確認と全体確認を終えるまで教材作成へ進みません。
- 通信取得に失敗した場合、正規のjpn.traineddata(.gz)をファイルから取り込めます。日本語モデルを別の言語に差し替えないでください。
- 写真・本文はタブのメモリ内のみ。閉じる・再読み込みの前に必要な教材JSONを保存してください。

## iPhoneでの再テスト

1. Safariで `https://moe2127.github.io/jugyo-note/?v=ocr5` を開きます。
2. 「日本語OCRの動作診断・再テスト」に「OCR改善版 v5」と表示されることを確認。
3. 「日本語OCRを診断する」を実行。初回は学習データ取得のため通信が必要です。
4. 教科書の写真を選び全ページを読み取り、文字化けが残る部分は「範囲・傾き・明るさを調整」で一段落ずつ指定。
5. 本文・注釈・図表のラベルと文字を修正し、原画像との照合チェックを入れます。図の意味・表の行列は自動復元しません。
6. Safariの共有メニューから「ホーム画面に追加」で起動可能。キャッシュは端末により削除されるため、完全なオフライン動作は保証しません。

強い台形歪み、ページの湾曲、ぼけは完全補正できません。可能なら正面から撮影し、見開きを1枚ずつ分けてください。HEICが開けない端末ではJPEGを使用。

## 教材作成

無料のChatGPTへ依頼文をコピーし、教材JSONを取り込む従来方式を維持。標準約20枚・50分、編集可能な図形のPowerPoint、生徒用プリント・教員用解答の印刷用HTMLを出力できます。本文の意味・解答・教科書との整合は教員が確認してください。

## 検証

`node tests/ocr.cjs` は画像処理の計算・品質判定・モデル形式・エラー処理・jpn専用の初期化呼出しを検証します。エンジン呼出しのテストはモックであり、実写真の精度テストではありません。

`node tests/verify.cjs` はPptxGenJSが必要です。20枚・50分、問題番号・記入指示、プリントと教員ノートの出力、失敗時の文章保持、ページ確認ゲートを検証します。

この開発環境では外向き通信プロキシの障害により、学習データの実取得・教科書写真での実OCR・Safari実機テストは未実施です。公開後、上記手順で再テストできます。
